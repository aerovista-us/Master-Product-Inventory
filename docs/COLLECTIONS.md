# AeroVista Product Families & NXCore mini.shops Source Inventory

**Observed:** 2026-10-12 · **Scope:** all AeroVista divisions · **Source of truth:** [Notion master inventory](https://app.notion.com/p/3f62a204d0c481e39d7ecec55dd67b48)

## Model

**Division → Product Family → Product Collection → Product → Edition / Template / Source Asset.** A collection is not an extra app by itself, and an album's source folder is not a sold software product. The Notion Projects data source now has `Product Family` (select) and `Product Collection` (text) fields; the master page has a family-grouped board. A separate EchoStories Program indexes content assets rather than inflating Type=Product.

**Verified snapshot totals:** 67 products; 8 product families; 25 distinct collection names; 76 top-level local folders; 33 named EchoStories child folders; 176 GitHub repositories remain their own source audit.
